ШИНЫ — статический тренажёр ОГЭ

Как загрузить на GitHub Pages:
1. Распакуйте архив.
2. Загрузите содержимое папки в корень репозитория.
3. В Settings → Pages выберите Deploy from a branch, branch main / root.
4. Главная страница — index.html.

Файлы:
- index.html — оболочка сайта
- styles.css — стили
- app.js — вся логика тренажёра
- assets/fig1.png, fig2.png — рисунки из предоставленного скрина ОГЭ
- assets/one_turn.gif — анимация одного оборота колеса

Важно:
- Структура включает вводный разбор, оба прототипа №1 и №2 в обучении, №3–5 и самостоятельный вариант.
- Визуальное позиционирование стрелок/облачков можно доточить позже.
- Числа и таблица примеров находятся в app.js и могут быть заменены на нужные конкретные варианты ФИПИ.
